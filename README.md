CLI that scaffolds folder structures from architecture presets.

## Features

- Interactive preset picker
- Ready-made layouts
- Snapshot any existing project's structure as a reusable preset

## Quick start

### Installation

```bash
npm i -g archdream
```

### Usage

Run from the folder where you want the layout, or pass a path:

```bash
archdream src
```

Run `archdream help` (or `-h`, `--help`) for command guidance and examples.
